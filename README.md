# Studio Equilíbrio — Sistema de Gestão Administrativa

> Case prático de aplicação de tecnologia para organização, automação e melhoria de processos administrativos de um Studio de Pilates e Fisioterapia.

## 📌 Sobre o projeto

O **Studio Equilíbrio** é um sistema de gestão desenvolvido a partir de necessidades reais identificadas na rotina administrativa de um Studio de Pilates e Fisioterapia.

O projeto surgiu da necessidade de centralizar informações que estavam distribuídas entre diferentes controles e reduzir atividades manuais relacionadas a alunos, horários, mensalidades, pagamentos e operação diária.

A proposta não foi apenas desenvolver um software, mas entender os processos existentes, identificar gargalos e criar uma solução que pudesse ser utilizada no dia a dia da operação.

## 🎯 Problema identificado

A administração de um Studio envolve diversos processos simultâneos, como:

* Cadastro e acompanhamento de alunos;
* Organização de horários;
* Controle de presença e faltas;
* Agendamento de reposições;
* Controle de mensalidades;
* Registro de pagamentos;
* Acompanhamento de caixa;
* Emissão de recibos;
* Controle de aulas experimentais;
* Lista de espera;
* Histórico operacional;
* Gestão dos equipamentos utilizados durante as aulas.

Quando essas informações ficam distribuídas em planilhas, anotações e diferentes ferramentas, atividades simples podem exigir várias etapas manuais.

## 💡 Solução desenvolvida

Foi desenvolvido um sistema web para centralizar essas operações em um único ambiente.

O sistema permite que a equipe administrativa e as instrutoras tenham acesso às informações necessárias de acordo com suas permissões, reduzindo retrabalho e facilitando a rotina do Studio.

O projeto continua evoluindo de acordo com situações encontradas durante sua utilização real.

* Acompanhamento das mensalidades;

### 💾 Backup

Foram desenvolvidas rotinas para proteção e recuperação das informações do sistema.

## 🧠 Tecnologia aplicada ao processo administrativo

Um dos principais objetivos deste projeto foi utilizar tecnologia para resolver problemas da operação.

Durante o desenvolvimento, situações da rotina administrativa foram analisadas individualmente para identificar oportunidades de:

* Reduzir tarefas repetitivas;
* Diminuir controles manuais;
* Evitar informações duplicadas;
* Centralizar dados;
* Melhorar a consulta de informações;
* Padronizar processos;
* Reduzir possibilidades de erro;
* Facilitar a tomada de decisão.

O desenvolvimento do sistema acontece de forma incremental: uma necessidade é identificada durante a operação, o processo é analisado, uma solução é desenvolvida, testada e posteriormente incorporada ao sistema.

## 🤖 Inteligência Artificial como ferramenta de produtividade

Ferramentas de Inteligência Artificial são utilizadas como apoio durante diferentes etapas do projeto, incluindo:

* Apoio ao desenvolvimento;
